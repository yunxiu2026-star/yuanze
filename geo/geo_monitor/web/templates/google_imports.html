如何导出

GA4

打开「报告」中的「流量获取情况」「网页和屏幕」或「人口统计信息详情」，选择日期后点击「共享此报告 → 下载文件 → CSV」。同一资源、同一日期范围的不同报告会组合展示；报告缺少的指标保持空白。

流量表的会话数按导入行汇总；分组活跃用户不能相加为去重访客数。

{% if not phase1 or growth %}

Search Console

进入「效果」，选择日期和搜索类型，点击「导出 → Excel」。推荐完整 Excel，包含每日、查询、网页、国家和设备；也可逐个上传 CSV 表。

总点击和总曝光来自每日表。查询可能匿名化，不能用查询表合计替代总量。当前按 Web 搜索展示，导出时请选择网页搜索。

本后台共用一个 Google 数据连接。移除本地授权会删除保存的令牌；Google 侧权限可在账号的第三方连接中撤销。

选择报告资源


GA4 管理 → 资源详情；填写数字 ID，非 G- 开头的衡量 ID。


域资源：sc-domain:{{ site }}；网址前缀资源：https://{{ site }}/。必须与 Search Console 中的一致。

首次授权：按这 5 步操作

  1. 在 Google Cloud 创建或选择一个项目，启用 Google Analytics Data API 与 Google Search Console API。
  2. 进入 Google Auth Platform，配置应用名称及联系邮箱。个人预览可选择外部、测试状态，并将自己的 Google 邮箱加入测试用户。
  3. 创建「Web 应用」OAuth 客户端，在「已获授权的重定向 URI」添加：{{ redirect_uri }}。确保访问后台也使用该地址的主机名。
  4. 下载客户端 JSON，将文件命名为 client.json，放到项目的 data/.google-private/ 目录。不要将文件或密钥发送到聊天中。放好后刷新本页。
  5. 点击「连接 Google 账号」，在 Google 页面登录并允许读取 Analytics 和 Search Console；返回后填写上方资源 ID，保存即可。

测试状态下的外部应用，离线令牌通常会在 7 天后过期，届时重新授权。以后部署到服务器时，需要登记对应 HTTPS 回调地址并设置 GOOGLE_REDIRECT_URI。

数据与权限

本功能只读取报告，不修改 Google 资源，也不安装网站埋点。客户端凭据、授权令牌和资源设置仅保存在服务器的私有目录，不会出现在网页源码或报告下载中。请限制该目录的本机访问权限，并保护备份。

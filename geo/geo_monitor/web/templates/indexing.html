如何使用

  1. 打开页面详情

    核对页面是否应该参与搜索排名。

  2. 检查 Google 状态

    已有只读授权时读取 URL Inspection 快照；也可在 Search Console 手工检查，再录入原始结果。

  3. 复查技术条件

    读取公开页面的 HTTP、noindex、robots、canonical 与站点地图信息，和 Google 结果分开判断。

Google API 只读取已有索引版本；不执行实时测试、不提交收录申请，也不修改官网。

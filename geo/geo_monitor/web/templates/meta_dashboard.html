  3. 登记授权回调地址

    在应用的登录配置中登记下面这个完整地址：

    {{ meta.redirect_uri }}

    正式后台使用 HTTPS 公网回调；复制上方地址到 Meta 的有效 OAuth 重定向 URI 中。若在本机演练，请始终使用同一个主机名。

  4. 保存配置并连接

    右侧密钥仅加密保存在当前后台的私有目录，不显示在页面中。连接后选择 {{ site_name }} 主页和关联的 Instagram，再同步数据。
